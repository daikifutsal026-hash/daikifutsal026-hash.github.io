プライバシーポリシー

最終更新日: 2026年11月18日

「朝の情報チャンネル」の運営者が使うツール「AutoTube」（以下「本アプリ」）での Google アカウント情報の扱いを定めます。

1. 本アプリについて

運営者が自分の YouTube チャンネルに動画を投稿・管理するためだけに使う個人用ツールです。運営者以外のログインは想定していません。

2. 使う権限と目的

  • youtube.upload: 運営者のチャンネルに動画とサムネイルを予約投稿するため
  • youtube.readonly: 投稿済み動画の状態を確認し、二重投稿を防ぐため
  • yt-analytics.readonly: 運営者のチャンネルの視聴データを集計し、番組の改善に使うため

得た情報はこの目的以外に使いません。

3. 保存場所

認証情報と取得したデータは運営者のパソコン内にだけ保存し、外部のサーバーには保存しません。

4. 第三者への提供

Google のユーザーデータを第三者に販売・提供・共有せず、広告にも使いません。

5. Google のポリシーの遵守

Google API から受け取った情報の使用と転送は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

6. アクセスの取り消し

Google アカウントの設定からいつでも取り消せます。保存済みの認証情報は運営者が削除します。

7. お問い合わせ

このページを公開している GitHub リポジトリの Issues からご連絡ください。
