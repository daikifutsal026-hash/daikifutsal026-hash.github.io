プライバシーポリシー

discord-notifier は、運営者本人が自分のアカウントのデータだけを扱う個人用ツールです。

読み取るデータ

  • Googleカレンダーの予定(読み取り専用)
  • Google Tasks のタスク(読み取り専用)
  • Gmail のメール(読み取り専用)
  • 運営者が指定した Discord チャンネルの投稿

利用目的

翌日の予定と当日のTODOをまとめ、運営者本人の Discord DM へ通知するためだけに利用します。広告には利用せず、販売もしません。

データの送信先

  • GitHub Actions: 通知処理の実行環境です。
  • Anthropic API: メールと Discord 投稿の本文の一部を送信し、予定とTODOを抽出します。
  • Discord: 作成した通知を運営者本人の DM へ送信します。

データの保存

本ツールは読み取った内容をデータベースやファイルに保存しません。実行ログには件数だけを記録します。送信先の各サービスでの取り扱いは、それぞれのポリシーに従います。

Google ユーザーデータの取り扱い

Google API から取得した情報の利用と転送は、Limited Use の要件を含む Google API サービスのユーザーデータに関するポリシーに従います。

アクセス権の取り消し

Google へのアクセス権は、Google アカウントの設定からいつでも取り消せます。
